# Global-Malnutrition-Trends-A-powerBi-analysis-1983-2019
🌍 Global Malnutrition Trends (1983–2019)
📊 A Power BI Data Analysis Project

This project presents a comprehensive Power BI analysis of global malnutrition trends from 1983 to 2019, providing insights into how nutrition levels, undernourishment, and related health indicators have changed over time across different countries and regions.
The goal of this project is to uncover patterns, highlight regions most affected by malnutrition, and support data-driven decision-making for global health and development initiatives.

📁 Project Overview
🎯 Objective

To analyze long-term global malnutrition patterns, identify high-risk regions, and understand key factors influencing nutritional health using interactive Power BI dashboards.

📊 Key Insights

--> Global malnutrition rates show steady improvement over the decades.

--> Certain regions — especially in Africa and South Asia — continue to face high malnutrition burdens.

Economic growth correlates strongly with improved nutrition levels.
